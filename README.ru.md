# GIF Cutout

Удаление белого, чёрного или любого однотонного фона у анимированных GIF прямо в браузере. Один файл, без установки, ничего не загружается на сервер.

![screenshot](docs/screenshot.png)

## Как пользоваться

- **Онлайн:** откройте **https://weavervictorwings.github.io/gif-cutout/**
- **Офлайн:** скачайте [`index.html`](index.html) и дважды щёлкните по нему. Это и есть вся установка.

## Быстрый старт

1. Перетащите GIF (или нажмите **Выбрать файл**; **Образец: белый фон** — чтобы сразу попробовать).
2. Посмотрите превью. Если края грязные — увеличьте **Допуск**.
3. Нажмите большую кнопку **Сохранить** внизу.

## Возможности

- Автоопределение фона; пипетка для любого другого однотонного цвета
- **Защита от протечек** и **автозаливка щелей**: тонкие линии в исходнике не прорезают щели в объекте
- Кисть и **волшебная палочка** для правки, отмена/повтор; сглаживание краёв, удаление ореола
- Обводка, тень, свечение, цветокоррекция; реверс, туда-обратно, прореживание кадров, новый фон
- Вход: GIF, APNG, WebP, PNG, JPG, вставка из буфера, пакетная обработка папок
- Выход: GIF (с целевым размером файла), APNG, анимированный WebP, PNG-кадры (zip), спрайт-лист
- 6 языков, определяются автоматически, переключатель слева вверху

## Ограничения

- Прозрачность GIF только «есть/нет», поэтому края слегка зубчатые. Для гладких краёв берите APNG или WebP.
- Для чтения анимации APNG/WebP нужен браузер с `ImageDecoder` (свежие Chrome, Edge, Safari); в остальных загрузится только первый кадр.
- Градиенты, тени и текстурные фоны нельзя идеально убрать однотонным методом; используйте ручные инструменты.
