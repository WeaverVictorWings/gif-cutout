# GIF Cutout

Удаление белого, чёрного или любого однотонного фона у анимированных GIF прямо в браузере. Один файл, без установки, ничего не загружается на сервер.

![screenshot](docs/screenshot.png)

## Как пользоваться

- **Онлайн:** откройте **https://weavervictorwings.github.io/gif-cutout/**
- **Офлайн:** скачайте [`index.html`](index.html) и дважды щёлкните по нему. Это и есть вся установка.

## Быстрый старт

1. Перетащите GIF (или нажмите **Выбрать файл**; **Образец: белый фон** — чтобы сразу попробовать).
2. Посмотрите превью. Если края грязные — увеличьте **Допуск**.
3. Нажмите большую кнопку **Сохранить** внизу.

## Возможности

- Автоопределение фона (даже «фальшивой прозрачной» шашечки); пипеткой можно добавить до 6 цветов фона
- **Защита от протечек** и **автозаполнение щелей**: тонкие линии в исходнике больше не прорезают объект
- Умная **волшебная палочка** (идёт по градиентам и текстурам, останавливается на контурах; допуск — перетаскиванием, Shift/Alt — добавить/вычесть, следует за объектом по кадрам), лассо, рамка, **умная кисть**, кисть-заливка; отмена / повтор везде
- Контур, тень, свечение, цветокоррекция; реверс, пинг-понг, пропуск кадров, новый фон
- Масштаб и перемещение, **C** — показать оригинал, начало / конец, копирование кадра как прозрачного PNG, горячие клавиши, запоминание настроек
- Ввод: GIF, APNG, WebP, PNG, JPG, вставка из буфера, пакетная обработка папок
- Вывод: GIF (целевой размер, число цветов, предсмешивание краёв), APNG, анимированный WebP, последовательность PNG (zip), спрайт-лист; несколько форматов сразу в одном zip
- Пресеты для стикеров (WeChat, Discord, Slack, LINE), дополнение до квадрата, рамка обрезки, объединение одинаковых кадров, оценка размера
- Также: **видео → анимация** (mp4 / webm, диапазон, fps, размер), **несколько картинок → одна анимация**, **подписи**; ручные правки **автоматически сохраняются в браузере** и предлагаются при повторном открытии файла; чек-лист перед экспортом и пресет WhatsApp; необязательная экспериментальная **ИИ-вырезка** (модель работает в браузере, скачивается при первом использовании)
- Над превью — три способа вырезания: **Убрать однотонный фон**, **ИИ-вырезание** и **Волшебная палочка** (щёлкните по фону, чтобы убрать его), для каждого файла подсказывается подходящий. Слишком большие анимации автоматически уменьшаются, чтобы браузеру хватило памяти; при экспорте сохраняется число повторов (бесконечно или N раз); страница не грузит внешние шрифты и открывается сразу даже там, где Google недоступен.
- Чище края: после вырезания **мелкие обрывки** вокруг объекта убираются автоматически (восстановленное вручную не трогается), а **сглаживание между кадрами** уменьшает мерцание неподвижных областей. Также: **разрезание спрайт-листа** на анимацию, **проверка зацикливания** с обрезкой в один клик, сдвиг **оттенка** и **мои пресеты** (хранятся в браузере).
- 10 языков, автоопределение, переключение вверху слева

## Ограничения

- Прозрачность GIF только «есть/нет», поэтому края слегка зубчатые. Для гладких краёв берите APNG или WebP.
- Для чтения анимации APNG/WebP нужен браузер с `ImageDecoder` (свежие Chrome, Edge, Safari); в остальных загрузится только первый кадр.
- Градиенты, тени и текстурные фоны нельзя идеально убрать однотонным методом; используйте ручные инструменты.
- ИИ-вырезание — экспериментальная функция: нужен доступ к cdn.jsdelivr.net / unpkg.com, модели скачиваются только при выборе (5–179 МБ, кэшируются в браузере). Сначала пробуется текущий кадр, чтобы вы проверили результат до обработки всех кадров; обрабатываются только кадры, которые будут экспортированы. Нет модели, подходящей для всех роликов («Универсальная, высокое качество» оказалась самой надёжной на наших 18 тестовых роликах). Скорость в браузере и ускорение WebGPU зависят от устройства.
