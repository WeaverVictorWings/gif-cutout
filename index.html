GIF 抠底台

拖入动图，去掉白底或黑底，导出透明 GIF、APNG、WebP、序列帧或精灵图。所有处理都在你的浏览器里完成，文件不会上传。

  1. 1. 拖入或选择一个动图
  2. 2. 看预览，边缘不干净就调「容差」
  3. 3. 点底部的大按钮导出
支持 GIF（推荐）、APNG、WebP、PNG、JPG。可拖入页面，也可 Ctrl+V 粘贴。
没有素材？
背景看起来比较复杂，只去纯色底可能抠不干净。可以用「点选去除」点一下去掉整块背景，或用笔刷修补。

快捷键
  • Space播放 / 暂停
  • ←→上一帧 / 下一帧
  • ERF擦除 / 恢复 / 补色画笔
  • Shift+EShift+R智能擦除 / 智能恢复
  • WLM魔棒 / 套索 / 框选
  • SD保留笔 / 去掉笔
  • EnterShift+Enter擦除选区 / 恢复选区
  • Ctrl+I反选
  • H显示擦掉的区域
  • I吸管
  • []画笔变小 / 变大
  • Esc退出当前工具
  • C按住时显示原图
  • +-0放大 / 缩小 / 适应窗口
  • Ctrl+滚轮 或触控板双指捏合：缩放预览
