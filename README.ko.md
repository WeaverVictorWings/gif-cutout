# GIF 배경 제거기 (GIF Cutout)

움직이는 GIF의 흰색·검은색 등 단색 배경을 브라우저에서 바로 지웁니다. 파일 하나, 설치 불필요, 업로드 없음.

![screenshot](docs/screenshot.png)

## 사용법

- **온라인:** **https://weavervictorwings.github.io/gif-cutout/** 열기
- **오프라인:** [`index.html`](index.html)을 내려받아 더블클릭하면 끝입니다.

## 3단계로 시작

1. GIF를 끌어다 놓기 (또는 **파일 선택**; **흰 배경 예시**로 바로 체험 가능).
2. 미리보기를 보고 가장자리가 지저분하면 **허용치**를 올리기.
3. 아래의 큰 **내보내기** 버튼 누르기.

## 기능

- 배경색 자동 감지(가짜 ‘투명’ 체크무늬도 인식), 스포이트로 최대 6색까지 추가
- **관통 방지**와 **자동 틈 메우기**로 원본의 가는 선이 피사체에 틈을 내지 않도록 보호
- 스마트 **마법봉**(그라데이션·질감을 따라 퍼지고 윤곽선에서 멈춤, 드래그로 허용치 조정, Shift/Alt로 추가/빼기, 프레임을 넘나들며 피사체 추적), 올가미, 사각형 선택, **스마트 브러시**, 색 채우기 브러시. 모든 작업 실행 취소/다시 실행
- 윤곽선, 그림자, 발광, 색 보정, 역재생, 왕복 재생, 프레임 건너뛰기, 배경 교체
- 확대·이동, **C** 길게 눌러 원본 보기, 시작 / 끝 지점, 현재 프레임을 투명 PNG로 복사, 단축키, 설정 자동 기억
- 입력: GIF, APNG, WebP, PNG, JPG, 붙여넣기, 폴더 일괄 처리
- 내보내기: GIF(목표 용량·색상 수·가장자리 사전 블렌딩), APNG, 애니메이션 WebP, PNG 시퀀스(zip), 스프라이트 시트. 여러 형식을 한 번에 zip으로
- 이모티콘 프리셋(WeChat, Discord, Slack, LINE), 정사각형 맞추기, 자르기 영역, 중복 프레임 합치기, 실시간 용량 추정
- 그 밖에: **동영상→애니메이션**(mp4 / webm, 구간·fps·크기 선택), **여러 이미지→하나의 애니메이션**, **자막** 추가. 수동 편집은 **브라우저에 자동 저장**되어 같은 파일을 다시 열면 복원할 수 있습니다. 내보내기 전 점검 목록과 WhatsApp 프리셋. 선택 기능인 **AI 누끼**(실험 기능, 모델은 브라우저에서 실행되며 처음에 다운로드)
- 미리보기 바로 위에 **단색 배경 제거**와 **AI 누끼** 두 가지 방식이 있고 파일마다 추천을 보여 줍니다. 너무 큰 애니메이션은 자동으로 줄여 메모리 부족을 막고, 내보낼 때 재생 횟수(무한 반복/N회)를 유지합니다. 외부 글꼴을 불러오지 않아 Google에 접속할 수 없는 환경에서도 바로 열립니다.
- 더 깨끗한 가장자리: 누끼를 딴 뒤 피사체 주변의 **잔여 조각**을 자동으로 지웁니다(수동으로 복원한 부분은 제외). **프레임 간 스무딩**으로 정지 부분의 깜빡임도 줄입니다. 그 밖에 **스프라이트 시트 나누기**, **반복 검사**(한 번에 가장 자연스러운 지점까지 자르기), **색조** 조정, **내 프리셋**(브라우저에 저장).
- 10개 언어 지원, 자동 감지, 왼쪽 위에서 전환

## 제한 사항

- GIF 투명도는 있음/없음 두 단계뿐이라 가장자리가 약간 거칩니다. 부드러운 가장자리는 APNG나 WebP를 쓰세요.
- APNG/WebP 애니메이션을 읽으려면 `ImageDecoder`를 지원하는 브라우저(최신 Chrome, Edge, Safari)가 필요하며, 그 외에는 첫 프레임만 불러옵니다.
- 그라데이션·그림자·질감 있는 배경은 단색 방식으로 완벽히 지울 수 없으니 수동 도구를 함께 쓰세요.
- AI 누끼는 실험 기능입니다. cdn.jsdelivr.net / unpkg.com에 접속할 수 있어야 하며, 모델은 선택할 때만 내려받습니다(5–179 MB, 브라우저에 저장). 먼저 현재 프레임만 시험해 확인한 뒤 전체를 처리하고, 내보낼 프레임만 처리합니다. 모든 소재에 맞는 모델은 없습니다(테스트 소재 18개에서는 '범용 고품질'이 가장 안정적). 브라우저 속도와 WebGPU 가속은 기기에 따라 다릅니다.
